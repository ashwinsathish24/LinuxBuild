=== Building yay ===
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

=== Fetching Caelestia Shell ==
1. git clone https://github.com/caelestia-dots/caelestia.git ~/.local/share/caelestia
2. Install the fish script in the installed location

=== Fetching Ashwin's Harmony Theme for Caelestia ===
git clone https://github.com/ashwinsathish24/LinuxBuild.git ~/Documents/LinuxBuild/
cd ~/Documents/LinuxBuild/

Copy everything from here to the - /etc/xdg/quickshell/caelestia/

=== Installing Packages ===
cat Packages.txt | xargs sudo pacman -S --needed

=== Optimizations ===
1. Fan control - sudo nbfc config -a (json name)
2. If middle mouse buttons dont work, Use these commands in order

cp SystemdScripts/Bin/razer-fix.sh /usr/local/bin/razer-fix.sh
sudo chmod +x /usr/local/bin/razer-fix.sh
cp SystemdScripts/Systemd/razer-fix.service /etc/systemd/system/razer-fix.service
sudo systemctl start razer-fix.service
sudo systemctl daemon-reload
